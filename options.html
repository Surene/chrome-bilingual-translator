DeepSeek API

Token 仅保存在当前浏览器的扩展本地存储中，并仅发送至 DeepSeek API。译文缓存保留 7 天后自动清理。

模型名称以 DeepSeek 账户可用范围为准。

将检测本机 Edge TTS 服务是否已启动。

需先在电脑上启动扩展目录中的 start-edge-tts-service.cmd。该服务无需 API Token；未检测到服务时会自动使用 Chrome 朗读。

使用豆包语音合成 2.0（seed-tts-2.0）。新版控制台只需填写 API Key；凭证仅保存在本机扩展存储中。
