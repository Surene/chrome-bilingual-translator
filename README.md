# 网页双语翻译 · Chrome 扩展

一个仅供个人使用的 Manifest V3 Chrome 扩展。它使用你自己的 DeepSeek API Token，为文章标题和正文生成中英双语对照译文，并将阅读、翻译练习与生词复习放在同一套轻量工作流中。

> 本项目不提供、也不会上传 API Token。所有配置、译文缓存、练习草稿和生词数据均保存在本机 Chrome 扩展存储中。

## 功能

- **中英双语对照**：保留原文，译文以卡片形式显示在原文下方；仅处理文章标题和正文，避开导航、按钮和代码块。
- **进度与缓存**：显示分段翻译进度与预计时间；相同译文在本机缓存 7 天，避免重复调用 DeepSeek。
- **翻译练习**：选中原文后从右键菜单或弹窗发起练习；DeepSeek 按句对照原文、参考译文与练习译文，给出评分、问题和知识点。
- **查词与指代说明**：在译文卡片中选中词语即可查看词义、用法和代词在上下文中的所指。
- **生词本**：同一个词合并为一个词条，保留多个完整例句和原文句；支持搜索、学习状态、随机复习，以及单词/例句朗读。
- **三种朗读方式**：Chrome 系统默认朗读、可选本地 Edge TTS、可选豆包语音合成 2.0。

## 安装扩展

1. 下载或克隆本仓库。
2. 在 Chrome 打开 `chrome://extensions`，启用右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开扩展弹窗，进入“管理 Token 和模型”。
5. 填写你的 DeepSeek API Token，保存后即可在普通网页中点击“翻译当前页面”。

扩展更新后，请刷新此前已打开的网页；旧页面中的 content script 会在更新后失效。

## DeepSeek 配置

在管理页填写 DeepSeek API Token，并选择账户可用的模型（默认 `deepseek-v4-flash`）。Token 仅用于请求 `https://api.deepseek.com`。

翻译缓存、查词缓存的保留期均为 7 天。管理页提供“清除翻译缓存”操作；隐藏当前页面译文不会删除缓存。

## 朗读服务

### Chrome 系统默认

默认模式。扩展不指定音色，直接由 Chrome 与操作系统决定适合当前中英文内容的默认朗读语音。

### Edge TTS（英文句子推荐）

本地 Edge TTS 服务可使英文长句更连贯。项目不需要把 Python 依赖放入 Chrome 扩展：首次启动时会在本机创建 `.edge-tts-venv`，该目录已被 Git 忽略。

1. 双击 `start-edge-tts-service.cmd`。
2. 首次运行会自动创建虚拟环境并安装 `edge-tts`；保持命令行窗口运行。
3. 在扩展管理页选择“使用 Edge TTS 本地服务”。

服务只监听 `http://127.0.0.1:8765`，并提供 `/health` 健康检查。扩展会在选择、保存和实际朗读前检测服务：**未检测到服务时会自动切换为 Chrome 本机朗读，不会发送 Edge TTS 合成请求。**

可在浏览器访问 `http://127.0.0.1:8765/health` 验证服务是否启动，正常会返回：

```json
{"ok": true, "service": "edge-tts"}
```

### 豆包语音合成 2.0

在管理页选择“使用豆包语音合成 2.0”，填写新版火山引擎控制台创建的 API Key。新版鉴权仅需 API Key；默认资源 ID 为 `seed-tts-2.0`，并预填以下音色：

- 中文：`zh_female_lingling_uranus_bigtts`
- 英文：`en_female_pleasant-female_uranus_bigtts`

点击“测试英文音色”可在保存前试听。每次豆包合成均会按火山引擎的计费字符规则计费，测试朗读也会产生用量。接口使用官方 V3 HTTP Chunked 协议，音频分片会在本地合并后播放。

## 使用方式

### 翻译网页

打开普通文章页面，点击扩展图标，然后点击“翻译当前页面”。关闭弹窗或点击网页不会取消已开始的翻译；再次打开弹窗可查看进度。Chrome 内部页面、Chrome 网上应用店及部分受限制页面无法注入扩展。

### 翻译练习

选中一段网页原文后：

- 点击扩展弹窗中的“翻译练习”；或
- 右键选择“使用 DeepSeek 进行翻译练习”。

输入内容会自动保存为本地草稿。提交后可查看逐句对照、参考译文、建议修改版、易错点和语法/短语/生词知识点。

### 查词与生词复习

在译文卡片中选中单词、短语或短句，即可查看释义并加入生词本。生词本按词条去重，但会累积不同的例句。管理页可搜索、标为“已掌握”、随机复习，并通过喇叭按钮朗读词条或例句。

## 项目结构

```text
chrome-bilingual-translator/
├─ manifest.json                 # Manifest V3 配置
├─ background.js                 # DeepSeek、缓存、查词、豆包 TTS 与右键菜单
├─ content.js / content.css      # 网页双语卡片、查词、练习面板
├─ popup.*                       # 扩展弹窗与翻译进度
├─ options.*                     # Token、朗读设置与生词本后台
├─ edge_tts_service.py           # 仅监听 localhost 的 Edge TTS 服务
├─ start-edge-tts-service.cmd    # Windows 启动脚本
├─ requirements-edge-tts.txt     # 本地服务依赖
└─ icons/                        # 扩展图标
```

## 隐私与安全

- DeepSeek Token 与豆包 API Key 使用 Chrome 的本地扩展存储保存，不会写入仓库。
- DeepSeek 仅接收需要翻译、查词或批改的文本。
- 豆包仅接收用户主动请求朗读的文本。
- Edge TTS 服务只绑定到 `127.0.0.1`，不对局域网开放。
- 请勿将含有真实 Token 或 API Key 的配置、截图和日志提交到 Git。

## 开发说明

无需构建步骤。修改扩展代码后，在 `chrome://extensions` 点击扩展的刷新按钮，并刷新正在测试的网页。

本项目为个人学习工具，请在遵守 DeepSeek、火山引擎、Microsoft Edge TTS 及目标网站服务条款的前提下使用。
